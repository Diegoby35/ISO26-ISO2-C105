# LAB-ISO2

## Proyecto: Sistema Integral de Gestión de Radiodiagnóstico (SESCAM)

Este repositorio constituye una línea base inicial para la práctica de Ingeniería del Software II. La implementación se ha centrado en modelar el dominio del sistema hospitalario de radiodiagnóstico descrito en el enunciado, con especial atención a:

- pacientes y personal sanitario
- tipos de prueba diagnóstica
- solicitudes y citas
- gestión de prioridad
- informes médicos y seguimiento periódico

La arquitectura está pensada para evolucionar siguiendo un ciclo iterativo e incremental y para adaptarse a un desarrollo guiado por casos de uso.

## Cómo compilar y probar

```bash
mvn test
```
