# Plan de desarrollo inicial

## Iteración 0: arquitectura y dominio

Objetivo:
- Consolidar el modelo de negocio del sistema de radiodiagnóstico.
- Definir actores, tipos de prueba y flujo principal de citas.
- Preparar una base de servicio listable para pruebas.

## Iteración 1: gestión de pacientes y solicitudes

Casos de uso principales:
- Registro de pacientes
- Solicitud de prueba diagnóstica
- Validación de requisitos previos

## Iteración 2: agenda y citas

Casos de uso principales:
- Programación de citas
- Confirmación y cancelación
- Gestión de prioridad y huecos de agenda

## Iteración 3: informes y seguimiento

Casos de uso principales:
- Registro de incidencias
- Emisión de informes
- Control de revisiones periódicas y seguimientos

## Iteración N: integración y cierre

Casos de uso principales:
- Integración de módulos
- Pruebas de integración
- Documentación de usuario y despliegue

## Estimación

Se asume una planificación incremental con una versión de módulo por iteración, siguiendo el principio de máxima coherencia y mínimo acoplamiento. Cada módulo debe tener una versión semver asociada y un conjunto claro de responsabilidades.
